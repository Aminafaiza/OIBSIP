# 🌡️ Temperature Converter

A responsive and user-friendly Temperature Converter built using HTML5, CSS3, and JavaScript. This application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with instant validation and accurate conversion results.

## 🚀 Live Demo

[View Temperature Converter](YOUR_LIVE_DEMO_LINK)

## 📌 Project Overview

The Temperature Converter is an interactive web application developed as part of the **Oasis Infobyte Web Development Internship – Level 1, Task 3**.

Users can enter a temperature, select the input unit, and convert it into the other temperature units.

## ✨ Features

- Convert between Celsius, Fahrenheit, and Kelvin.
- Display all three conversion results simultaneously.
- Real-time input validation.
- Reject empty or invalid temperature values.
- Absolute-zero validation.
- Display results rounded to two decimal places.
- Responsive design for desktop and mobile devices.
- Clean interface with a modern gradient background.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Temperature conversion and input validation.

## 📐 Conversion Formulas

- Celsius to Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit to Celsius: `(F − 32) × 5/9`
- Celsius to Kelvin: `C + 273.15`
- Kelvin to Celsius: `K − 273.15`

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the `WebDev-L1-TemperatureConverter` folder.
3. Open `index.html` in your web browser.
4. Enter a temperature.
5. Select Celsius, Fahrenheit, or Kelvin.
6. Click **Convert Temperature** to view the results.
